# Protótipos

Wireframes estáticos em HTML (sem scripts) das telas do painel. Servem para validar layout e fluxo antes do código e como referência visual. Os dados são fictícios e genéricos.

Abra qualquer arquivo diretamente no navegador (a navegação entre eles funciona por links relativos).

| Protótipo | Tela | Requisitos | Casos de uso |
|---|---|---|---|
| [login.html](login.html) | Login | RF-01 | UC-01 |
| [terminais.html](terminais.html) | Terminais | RF-03 a RF-06 | UC-03, UC-04 |
| [tarefas.html](tarefas.html) | Tarefas agendadas | RF-07 a RF-10, RF-25 | UC-05 |
| [servicos.html](servicos.html) | Serviços | RF-11 a RF-14, RF-25 | UC-08, UC-09 |
| [docker.html](docker.html) | Docker | RF-15, RF-16 | UC-10 |
| [processos.html](processos.html) | Processos e portas | RF-17, RF-25 | UC-11 |
| [monitor.html](monitor.html) | Monitor de recursos | RF-28 a RF-31 | UC-14 |
| [provedores.html](provedores.html) | Status dos provedores e exemplo de aba | RF-18 a RF-23 | UC-12, UC-13 |
| [modal-tarefa.html](modal-tarefa.html) | Nova tarefa e confirmação por nome | RF-10, RF-27 | UC-06, UC-07 |

Mapa de navegação em [mapa do site](../produto/mapa-do-site.md).

**Manutenção:** ao mudar uma tela, atualize o protótipo correspondente no mesmo PR ([definição de pronto](../processo/definicao-de-pronto.md)).
